# Study：问题、实践与设计依据

agent-loop 是服务于其他研究与工程项目的 harness。这里按它需要解决的问题组织调研，记录
外部实践、适用条件与本库取舍。当前架构以 [`design.md`](../design.md) 为准，执行方法见
[`skills/README.md`](../skills/README.md)，真实运行证据见 [`case_study/`](../case_study/)。

| 主题 | 要回答的问题 | 文档与定位 |

初次阅读：设计沿革 → 业界实践与能力边界 → 按问题进入专题。需要使用或修改当前实现时，
先读根目录设计与对应 owner，再查这里的依据。

社区项目的用途对照见 [Related projects](../docs/related-projects.md)，面向选择工具的读者；
本目录保留机制分析与设计依据。

## 文档边界

- **当前设计**说明系统现在如何工作，归根目录 `design.md` 与对应 owner。
- **已落地专题**解释为什么这样做；文中的历史缺口应明确标记，不能继续冒充当前状态。
- **外部调研**记录来源、读取日期或版本、机制与适用条件；阅读公开文档不等于实测。
- **研究方向**保留候选思路，不自动成为实现计划或新 gate；具体开发方向归公开 backlog。

理解，本次未逐一重新核验。保留原路径，避免破坏已有引用。
